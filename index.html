Mint via agent

Prompt 4 baris • direct execute

Mint RPIECE hanya lewat agent dengan Binance Agent ID — tidak ada tombol mint manual. Kontrak belum deploy, jadi prompt di bawah aktif dipakai setelah alamat kontrak resmi diumumkan. Jangan mint ke alamat mana pun sebelum pengumuman resmi.

1

Ambil Agent ID. Di aplikasi Binance, buka Agentic Wallet dan klaim Agent ID kamu. Sisakan sedikit BNB untuk gas.

2

Hubungkan AI kamu. AI apa pun yang terhubung ke Agentic Wallet bisa dipakai.

3

Copy prompt, kirim ke agent. Agent mint keping berikutnya sesuai urutan — Pointer dulu, lalu Ember, Verdant, Frost, Void.

4

Ulangi sampai lengkap. Maks 5 keping per wallet. Set lengkap membuka staking pool BNB.

FAQ

Apa itu Rifera Cursor Pieces?

Koleksi NFT baru bernama RPIECE: satu kursor panah pixel yang dipecah jadi 5 pita horizontal — Pointer, Ember, Verdant, Frost, dan Void. Kelima pita bertumpuk menyusun satu kursor utuh.

Sudah bisa mint?

Belum. Kontrak RPIECE belum deploy dan belum ada alamat kontrak. Prompt mint di halaman ini disiapkan untuk dipakai setelah alamat resmi diumumkan. Jangan kirim BNB ke alamat mana pun yang mengatasnamakan RPIECE sebelum itu.

Berapa harga tiap keping?

Keping 1 Pointer FREE (gas saja). Keping 2 Ember, 3 Verdant, 4 Frost, dan 5 Void masing-masing 0,002 BNB. Satu set lengkap total 0,008 BNB, maks 5 keping per wallet, mint wajib berurutan.

Kenapa harus pakai agent?

Mint RPIECE wajib Binance Agent ID. Kamu kirim prompt 4 baris, agent kamu yang memanggil kontrak — tidak ada tombol mint manual untuk manusia.

Game Shard Rush ini apa?

Game browser gratis 100 ronde dengan 4 gaya yang bergantian tiap ronde — RUSH (kumpulkan 5 keping), DODGE (bertahan sampai waktu habis; keping memberi bonus skor dan +5 detik), CHASE (tangkap 5 keping yang kabur), BLITZ (30 detik, kumpulkan keping sebanyak-banyaknya, minimal 5 untuk lolos). Gerakkan kursor (mouse, sentuh, atau WASD) dan hindari glitch. Timer menyusut tiap 10 ronde dari 60 sampai 30 detik, glitch makin banyak dan cepat. Nyawa 3 untuk seluruh permainan, +1 tiap 20 ronde selesai (maks 5). Tamatkan ronde 100 untuk jadi CURSOR MASTER. Tidak perlu wallet untuk main, dan skor game bukan jumlah mint.

Set lengkap gunanya apa?

Set 5 keping lengkap dalam satu wallet memenuhi syarat staking pool BNB. Detail pool diumumkan saat kontrak deploy.
