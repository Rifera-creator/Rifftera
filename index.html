FAQ

Game Shard Rush ini game apa?

Game browser gratis 60 detik: gerakkan kursor (mouse, sentuh, atau WASD), sentuh 5 keping untuk mengumpulkannya, hindari glitch (3 nyawa). Kumpulkan semua sebelum waktu habis untuk menang. Tidak perlu wallet untuk main. Angka di game (5 keping, 60 detik, 3 nyawa, skor) adalah aturan permainan — bukan jumlah mint atau stok NFT.

Apa itu 5 pieces, one cursor?

Itu koleksi Rifera Cursor Pieces (RPIECE), terpisah dari First Take dan belum di-deploy. First Cursor utuh disusun dari 5 keping: Pointer (FREE), Ember, Verdant, Frost, Void (masing-masing 0,002 BNB). Maks 5 keping per wallet — 1 set saja — total set lengkap 0,008 BNB, wajib Agent ID. Set lengkap bisa diposisikan untuk stake.

NFT Rifera itu gambar apa?

Satu take = satu kursor panah pixel utuh — karakter yang sama dengan yang kamu mainkan di game. Bentuknya selalu panah pointer (bukan I-beam); yang beda tiap take adalah palet warna dan pola pixelnya, digambar dari nomor take itu sendiri.

Game ini on-chain?

Tidak. Shard Rush adalah game browser gratis & off-chain. Mint, upgrade, dan claim yang asli hanya lewat agent di kontrak resmi di atas.

Kenapa harus pakai agent?

Mint Rifera wajib Binance Agent ID. Kamu kirim prompt 4 baris, agent kamu yang memanggil kontrak — tidak ada tombol mint manual untuk manusia.

Berapa biaya mint & upgrade?

Untuk First Take (live, 7.620 take, 195 sudah mint, 7.425 sisa): mint pertama per wallet FREE (gas saja), extra mint 0,002 BNB per take, tanpa maks per wallet. Upgrade 0,002 BNB per level, 1 level per panggilan. Untuk Pieces RPIECE (belum deploy): keping 1 FREE, keping 2–5 masing-masing 0,002 BNB, set lengkap 0,008 BNB, maks 5 keping per wallet. Agent ID wajib untuk keduanya.

Bagaimana cara claim $CURSOR?

Setelah mint, claim langsung tanpa snapshot lewat prompt Claim. Fee claim 0,00021 BNB per take, besar claim mengikuti level take kamu (Lv1 5% sampai Lv5 35% dari pool level itu).

Kapan $CURSOR bisa ditrade?

Belum. Pairing LP ditahan dan jatah LP belum di-pairing. Pengumuman hanya lewat rifera.xyz dan X @FirstTake_xyz — jangan percaya pair lain.
